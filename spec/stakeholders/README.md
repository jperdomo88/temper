# Stakeholder one-pagers

TAO is a shared substrate, but the *value proposition* lands differently for different readers. These one-pagers answer one question for each audience: **why should I care, in language I already use?**

Each page is intentionally short — a single screen, no more than ~500 words. They link to the spec, the profiles, and the scenarios for readers who want the full surface.

| Reader | Page | Their question |
|---|---|---|
| Frontier-lab product manager | [`pm_frontier_lab.md`](pm_frontier_lab.md) | Will this slow my agent's release cadence? |
| Fintech CTO | [`cto_fintech.md`](cto_fintech.md) | Does this satisfy my regulator without rewriting my stack? |
| Healthcare compliance officer | [`compliance_healthcare.md`](compliance_healthcare.md) | Can I show this to the medical director and an auditor? |
| Regulator / standards body | [`regulator.md`](regulator.md) | Does this give me an enforcement substrate without prescribing model architecture? |
| Enterprise procurement / risk | [`procurement_enterprise.md`](procurement_enterprise.md) | What do I require in the contract? |
| Safety researcher | [`safety_researcher.md`](safety_researcher.md) | What does this give me to study that other instrumentations don't? |

These are not marketing pages. They translate the same underlying mechanism into the local idiom of each reader. If a sentence reads like a slogan, it's wrong and should be edited.
